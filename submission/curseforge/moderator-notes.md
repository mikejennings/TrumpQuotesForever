# Notes for the moderation team

Please review the full, unchanged v0.8.0 addon. All 1,013 quotes are retained, including profanity, sexual references, personal insults, and disputed claims. The bundled catalog and source ledgers document the collection. No claim of prior content approval is made.

The optional timer attempts channel sends automatically. It defaults to 10–20 minutes and is OFF after every login/reload. User-configurable bounds are 1–1,440 minutes. A 60-second send cooldown applies; automatic sends skip AFK/instances and stop on detected API restrictions or blocked actions. A chat-editor preparation fallback requires the player to press Enter. Live-client public-channel delivery has not been verified; testing used Lua mocks and UIForever.

The upload is the existing v0.8.0 installation ZIP, without content or behavior changes. This is a free addon with inspectable Lua, no telemetry, and no in-game network fetching. Quote updates are prepared separately and reviewed before publication.

The project icon is original AI-generated decorative artwork; it is not a game screenshot or an official logo.
