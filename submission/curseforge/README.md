# CurseForge submission kit — version 0.8.0

Status: prepared for upload; not submitted or approved. All 1,013 quotes and existing posting behavior are unchanged.

1. Use a pseudonymous CurseForge author account/profile. Public credit in these materials is TQ Maintainers; the service still receives the account information used to sign in. Check the public profile before creating the project.
2. Create a World of Warcraft Addons project named **Trump Quotes**, subject to name availability. Select Chat & Communication, use the summary/description in listing.md, and upload icon-400.png.
3. Choose **All Rights Reserved** to reflect the current absence of an open-source license. This does not grant rights over third-party quotations or source material. No new license is applied to the existing addon by this kit.
4. Upload **TrumpQuotesForever-0.8.0.zip** as the addon file. Do not upload the outer CurseForge-kit ZIP. The inner ZIP already has the required TrumpQuotesForever root folder and matching TOC.
5. Select the supported Forever game version from the form. Interface 16001 identifies the client interface, not the site's numeric game-version ID. Use the file display name from project-fields.json and paste changelog.md.
6. Start with **Beta** because live-client public-channel delivery remains unverified. Use manual release if offered. Provide moderator-notes.md in a reviewer/private notes field if available; otherwise retain it for support correspondence. Do not publish those notes as a substitute for the complete public description.
7. Review the actual listing, account identity, selected game version, file type, and terms before submitting. CurseForge decides whether changes are needed. Normal app availability may require an approved Release file after testing.

The installation ZIP is byte-identical to the existing v0.8.0 release. SHA256SUMS.txt records its checksum and the supporting materials. The artwork is an original AI-generated decorative icon, not a screenshot.

No account, project, upload token, or CurseForge publishing workflow has been created. GitHub remains the current distribution channel, and daily quote collection continues to prepare updates for review only.
