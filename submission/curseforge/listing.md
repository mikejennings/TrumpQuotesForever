# Trump Quotes

## Summary

Browse 1,013 Donald Trump quotes, choose a chat channel, and configure an optional random posting timer for WoW Forever.

## Description

Trump Quotes is an unofficial collection of 1,013 attributed Donald Trump quotes for WoW Forever. The complete collection includes insults, profanity, explicit sexual references, controversial statements, and claims that may be false or disputed. It is supplied unfiltered; there is no content filter. Quoting a statement does not establish that it is true or endorse it.

Open the settings window with the TQ minimap button or `/tq`. Select a joined chat channel, preview a random quote, prepare it in the chat editor, or configure the optional random posting timer. General is the default channel. The timer defaults to a random interval of 10–20 minutes, supports settings from 1–1,440 minutes, and always starts off after login or reload.

When enabled, the timer attempts to send quotes to the selected channel. The addon enforces a 60-second send cooldown, skips automatic sends while AFK or in instances, and stops the timer when a restricted API or blocked action is detected. Automatic delivery to public channels depends on the live client's restrictions and is not guaranteed. Use Prepare Quote and press Enter yourself if automatic sending is unavailable.

The package includes the full quote catalog and source/context notes. New quote additions are reviewed on GitHub before publication; the addon does not download quotes while the game is running. It contains readable Lua source, no telemetry, and no external updater.

Version 0.8.0 targets Forever interface 16001. Lua tests and the UIForever simulator have been checked; live-client public-channel delivery has not been verified. This initial upload is for testing and moderator review.
