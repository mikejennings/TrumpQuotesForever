## Description

Trump Quotes is an unofficial quote collection for WoW Forever. Preview a random
quote locally, select a joined chat channel, and prepare a message to review and
send yourself.

The settings window opens from the TQ minimap button or `/tq`. Optional random
reminders prompt you locally; each shared message requires your own send action.
The addon does not automatically post reminders into public channels.

Quotes are short excerpts with source and context notes. They include opinions,
boasts and attributed claims; inclusion does not establish that an underlying
claim is true. The collection is curated for this edition, and suggestions for
new entries are reviewed before being included in a release.

This is an independent project and is not affiliated with or endorsed by Donald
Trump, Blizzard Entertainment, or CurseForge. It is free, with inspectable Lua
code. Use chat considerately and follow the game's chat rules.
